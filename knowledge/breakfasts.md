# South Indian Breakfast Menus — Chennai Family

> **How to add a new breakfast:**
> Create a new `##` section following the format below.
> Tags control when a meal is selected. Ingredients use the format:
> `- Name: quantity unit | Category`
>
> Valid tags: `vegetarian`, `non_vegetarian`, `egg`, `fish`, `chicken`, `mutton`, `mushroom`,
>             `saturday_special`, `light`, `heavy`, `fermented`, `festive`
>
> Valid categories: `Grains`, `Vegetables`, `Fruits`, `Proteins`, `Dairy`, `Spices`, `Oils`, `Other`
