# South Indian Dinner Menus — Chennai Family

> **How to add a new dinner:**
> Create a new `##` section. Tags control when a meal is selected.
>
> **Key tags for dinner selection:**
> - `sunday_special` — used for Sunday non-veg feast
> - `chicken` — qualifies as the mid-week chicken dinner (Wed)
> - `mushroom` — qualifies as the weekly mushroom dish (Tue)
> - `vegetarian` / `non_vegetarian` — protein type
> - `fish`, `egg`, `mutton`, `prawns` — specific protein
> - `light`, `heavy`, `festive`
>
> Valid categories: `Grains`, `Vegetables`, `Fruits`, `Proteins`, `Dairy`, `Spices`, `Oils`, `Other`
